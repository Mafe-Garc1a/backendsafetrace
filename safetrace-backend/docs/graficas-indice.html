Modelos de ecuaciones diferenciales del índice

Vibración libre, resonancia y atenuación, dibujadas con los datos del último índice calculado de un inmueble.

Cargar los datos de tu inmueble

  1. En Swagger ejecuta GET /inmuebles/{inmueble_id}/indice/modelos.
  2. Copia todo el Response body.
  3. Pégalo aquí y pulsa Graficar.

1. Vibración libre amortiguada

m·x'' + c·x' + k·x = 0

2. Resonancia con el suelo

m·x'' + c·x' + k·x = −m·asuelo(t)

3. Atenuación de la onda con la distancia

∂²u/∂t² = v²·∇²u

Índice orientativo calculado por el sistema; no es una evaluación profesional.
